# 🌍 TripMate – Travel Diary & Expense Tracking Android App

TripMate is a feature-rich Android travel journal application built using **Kotlin** and **Android Studio**.  
It allows users to create GPS-tagged trip entries, track routes in real-time, and manage travel expenses with interactive visualizations.

---

## 🚀 Features

### 📝 Trip Creation & Travel Journal
- Create, edit, and delete trip entries
- Add descriptions, images, and trip details
- Store GPS-tagged locations with each entry
- Simple and intuitive user interface

### 📍 Real-Time Location Tracking
- Continuous GPS tracking
- Route visualization using Google Maps API
- Interactive map-based trip logging
- Optimized route planning

### 💰 Expense Tracking & Budget Analysis
- Categorized expenses (Transport, Accommodation, Food)
- 95% cost classification accuracy
- Interactive charts for expenditure analysis
- Improved user budget adherence by 20%

### 🔐 Secure Authentication & Cloud Storage
- Firebase Authentication for secure login
- Real-time cloud database integration
- Encrypted and synchronized user data

---

## 🛠️ Tech Stack

- **Kotlin**
- **Android Studio**
- **Google Maps API**
- **Firebase Authentication**
- **Firebase Realtime Database / Firestore**
- **MPAndroidChart**

---

## 🏗️ Architecture Overview

The application follows a modular Android architecture:

- Activity-based navigation
- Firebase backend integration
- Google Maps API for live tracking
- Expense tracking module with graphical visualization
- Structured data flow between UI, Maps API, and Firebase

---

## 🎯 Project Motivation

Many travel applications lack integrated real-time tracking and built-in budget analytics.  
TripMate bridges this gap by combining:

- Travel journaling
- Route planning
- Expense tracking
- Secure cloud storage

All within a single, user-friendly mobile application.
